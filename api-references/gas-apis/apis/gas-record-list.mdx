---
title: 查询记录
api: GET /api/tron/gas/record/list
description: "通过id获取特定的代理记录"
---

#### 请求参数数据结构

<ParamField query="request_ids" type="string" required>
  多个request_id的字符串，英文逗号分割，例:123,345
</ParamField>

#### 响应参数数据结构

<Expandable title="object">
  <ResponseField name="id" type="integer">
    订单ID
  </ResponseField>
  <ResponseField name="trade_no" type="string">
    订单号
  </ResponseField>
  <ResponseField name="request_id" type="string">
    业务方ID
  </ResponseField>
  <ResponseField name="status" type="integer">
    状态：`0` 创建订单成功,  `1` 代理资源成功,  `2` 代理资源失败, `3` 部分成功, `10` 回收成功
  </ResponseField>
  <ResponseField name="service_charge_type" type="string">
    服务费类型。能量和带宽速充均固定为 `10000`。
  </ResponseField>
  <ResponseField name="receive_address" type="string">
    资源接收地址
  </ResponseField>
  <ResponseField name="amount" type="decimal">
    支付金额。速充订单在结算完成前为按购买数量计算的预估金额，结算完成后更新为最终结算金额。
  </ResponseField>
  <ResponseField name="energy_num" type="integer">
    能量数量
  </ResponseField>
    <ResponseField name="delegate_energy_num" type="integer">
    已代理能量数量
  </ResponseField>
   <ResponseField name="reclaim_energy_num" type="integer">
    已回收能量数量
  </ResponseField>
    <ResponseField name="net_num" type="integer">
    带宽数量
  </ResponseField>
   <ResponseField name="delegate_net_num" type="integer">
    已代理带宽数量
  </ResponseField>
    <ResponseField name="reclaim_net_num" type="integer">
    已回收带宽数量
  </ResponseField>
    <ResponseField name="order_source" type="integer">
    状态：`0` 手动下单,  `1` api购买,  `2` 自动租赁, `3` 能量转租
  </ResponseField>
  <ResponseField name="item_list" type="string">
    能量子订单
    <Expandable title="object">
      <ResponseField name="energy_num" type="integer">
        能量代理数量
      </ResponseField>
      <ResponseField name="energy_price" type="string">
        能量价格,单位sun
      </ResponseField>
      <ResponseField name="energy_txid" type="string">
        能量代理TXID
      </ResponseField>
      <ResponseField name="delegate_time" type="string">
        代理时间
      </ResponseField>
      <ResponseField name="resource_address" type="string">
        发送资源地址
      </ResponseField>
      <ResponseField name="reclaim_txid" type="string">
        能量回收TXID
      </ResponseField>
      <ResponseField name="reclaim_time" type="string">
        能量回收时间
      </ResponseField>
    </Expandable>
  </ResponseField>
  <ResponseField name="net_item_list" type="string">
    带宽子订单
    <Expandable title="object">
      <ResponseField name="net_num" type="integer">
        带宽代理数量
      </ResponseField>
      <ResponseField name="net_price" type="string">
        带宽价格,单位sun
      </ResponseField>
      <ResponseField name="net_txid" type="string">
        带宽代理TXID
      </ResponseField>
      <ResponseField name="delegate_time" type="string">
        代理时间
      </ResponseField>
      <ResponseField name="resource_address" type="string">
        发送资源地址
      </ResponseField>
      <ResponseField name="reclaim_txid" type="string">
        带宽回收TXID
      </ResponseField>
      <ResponseField name="reclaim_time" type="string">
        带宽回收时间
      </ResponseField>
    </Expandable>
  </ResponseField>
  <ResponseField name="swap_info" type="object">
    能量或带宽速充信息，仅速充订单返回；普通订单不返回该字段。
    <Expandable title="object">
      <ResponseField name="address" type="string">速充接收地址</ResponseField>
      <ResponseField name="energy_used" type="integer">速充前已使用能量</ResponseField>
      <ResponseField name="energy_num" type="integer">速充前可用能量</ResponseField>
      <ResponseField name="buy_energy_num" type="integer">用户原始购买能量数量</ResponseField>
      <ResponseField name="send_energy_num" type="integer">实际代理能量数量</ResponseField>
      <ResponseField name="end_energy_used" type="integer">回收完成后已使用能量</ResponseField>
      <ResponseField name="end_energy_num" type="integer">回收完成后可用能量</ResponseField>
      <ResponseField name="freeze_energy_num" type="integer">首次冻结采用的能量基数</ResponseField>
      <ResponseField name="net_used" type="integer">速充前已使用质押带宽，不含免费带宽</ResponseField>
      <ResponseField name="net_num" type="integer">速充前可用质押带宽，不含免费带宽；不是本单购买量</ResponseField>
      <ResponseField name="buy_net_num" type="integer">用户原始购买带宽数量</ResponseField>
      <ResponseField name="send_net_num" type="integer">实际代理带宽数量，不代表最终计费数量</ResponseField>
      <ResponseField name="end_net_used" type="integer">回收完成后已使用质押带宽，不含免费带宽</ResponseField>
      <ResponseField name="end_net_num" type="integer">回收完成后可用质押带宽，不含免费带宽</ResponseField>
      <ResponseField name="freeze_net_num" type="integer">首次冻结采用的带宽基数，不代表最终计费数量</ResponseField>
      <ResponseField name="freeze_amount" type="string">首次冻结金额，单位TRX</ResponseField>
      <ResponseField name="current_lock_amount" type="string">当前剩余冻结金额，单位TRX</ResponseField>
      <ResponseField name="settlement_amount" type="string">最终结算金额，单位TRX。按回收完成后系统确认的最终资源计费数量与下单时的价格、费率快照计算</ResponseField>
    </Expandable>
  </ResponseField>
</Expandable>
