#### Request Parameters

<ParamField query="request_id" type="string" required>
  request id.cannot be reused for repeated submissions. Maximum 32 characters, letters, numbers, underscores (`_`), and hyphens (`-`) only.
</ParamField>
<ParamField query="receive_address" type="string" required>
  receive address
</ParamField>
<ParamField query="buy_type" type="integer">
    0: Specified quantity 1: System estimation , default is 0 if not specified.
    <Note>
   **All methods are subject to minimum purchase value limits.：**
   - The minimum purchase quantity for bandwidth is 5000.
   - The minimum purchase quantity for energy is 64400.

1. **System estimates (buy_type = 1)**  
   - Please ensure that the receive_address holds the token corresponding to the contracte_address, otherwise the miner fee estimation will fail
   - Only allow the purchase of energy,Purchasing bandwidth is not supported. 

2. **When the customer specifies a quantity (buy_type = 0), they cannot purchase both energy and bandwidth simultaneously.**  
   - Only one of `energy_num` and `net_num` can be selected.  

3. **Parameter requirements when buy_type = 0**  
   - Please fill in at least one of the fields: `energy_num` or `net_num`.
  
  </Note>
</ParamField>
<ParamField query="service_charge_type" type="string" required>
  rent time code: Request the order/price interface to return the cost codes for
  minutes, hours, days, and different times.
  <p>eg:10010 - 10 minutes, 20001 - 1 hour, 30001 - 1 day</p>
  <Note>
    Energy or bandwidth flash recharge type `10000` is not supported by this endpoint. Use `/api/tron/gas/flash/open` instead.
  </Note>
</ParamField>
<ParamField query="energy_num" type="integer" >
  energy num : min value is 64000
    <Note>
        If buy_type=0, please enter the specific amount of energy
    </Note>
</ParamField>
<ParamField query="net_num" type="integer">
    net num : min value is 5000
    <Note>
         If buy_type=0, please enter the specific amount of net
    </Note>
</ParamField>
<ParamField query="address_to" type="string" >
    The transfer address for estimating miner fees.
    <Note>
        Required when selecting **buy_type=1**.
    </Note>
</ParamField>
<ParamField query="contract_address" type="string" >
    Contract address for estimating miner fees.
    <Note>
        Required when selecting **buy_type=1**.
    </Note>
</ParamField>
