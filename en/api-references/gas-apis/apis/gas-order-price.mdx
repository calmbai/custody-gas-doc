#### Request Parameters

<ParamField query="resource_type" type="string" required>
  Resource type, defaults to "energy". Examples: "energy" or "net"
</ParamField>
<ParamField query="service_charge_type" type="string">
  Service charge type. If omitted, all supported types are returned. `10000` represents energy or bandwidth flash recharge; `10010` represents 10 minutes, `20001` represents 1 hour, and `30001` represents 1 day.
</ParamField>
